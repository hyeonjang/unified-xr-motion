The rapid diversification of XR devices has intensified hardware heterogeneity, requiring vendor-specific pipelines to author and deploy consistent avatar motion across hardware configurations.
We introduce MotionDAG, a modular runtime architecture that unifies creator-facing motion composition and developer-level system extension within a shared directed acyclic graph (DAG) abstraction. 
Built on a publish–subscribe model, the runtime supports reusable motion-stage assets for creators while enabling engineers to extend triggers, computational nodes, and retargeters through shared interfaces.
It further supports selective server-side execution of computationally intensive stages, allowing complex motion graphs to run on resource-constrained XR devices.
To evaluate MotionDAG, we conducted a controlled within-subject study ($N = 19$) comparing it with an industry-representative workflow on the same authoring task.
MotionDAG reduced configuration time by 409 s (42\%), decreased NASA–TLX workload by 19.2 points (38.6\%), and improved SUS from 34.5 to 73.4.
